# Chair yoga. 5 min warmup at desk.

Bookmarked from a YouTube video. Routine for stiff shoulders after long laptop sessions.

1. Neck rolls. 3 each direction. Slow.
2. Shoulder shrugs. 10 reps. Hold at top for 2 sec.
3. Seated cat-cow. 5 cycles. Inhale arch, exhale round.
4. Seated spinal twist. 30 sec each side. Hand on opposite knee.
5. Wrist circles. 10 each direction. Both hands.
6. Ankle circles. 10 each direction.

End with 3 deep breaths. Back to work.
Reminder: do this after every 90-min focus block. Calendar block set 11:30 and 15:30.
